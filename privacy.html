MailMind AI - Privacy Policy

Last updated: October 20, 2026

MailMind AI is an experimental AI-powered email classification application designed to help users organize and prioritize their Gmail Inbox.

1. Information We Access

With your authorization through Google OAuth, MailMind AI accesses Gmail messages to provide email classification and organization features. The application requests Gmail modification permission, which can permit reading messages and modifying message labels or status.

The application may process email senders, subjects, message content, and message metadata. We do not ask for your Gmail password.

2. How We Use Information

Gmail information is used to classify Inbox messages into Priority, Review, and Spam categories, provide classification explanations, and support user-directed email management.

User preferences and classification corrections help personalize future recommendations.

3. Data Storage

MailMind AI uses Supabase to store personalization profiles and classification feedback. Feedback records may contain email sender addresses, subject lines, predicted categories, and user corrections.

Inbox classification results are maintained in the active application session rather than in the Supabase profile and feedback tables. OAuth credentials are used during the session to access Gmail.

4. Data Sharing

MailMind AI uses service providers necessary to operate the application, including Google APIs and Supabase. We do not sell Gmail information or use it for advertising.

5. Google API Services

MailMind AI's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google API Services User Data Policy

6. User Control

Users can disconnect Gmail within the application. Users can also revoke Google's authorization through their Google Account permissions:

Manage Google Account Connections

Disconnecting Gmail does not automatically delete previously stored personalization or classification feedback.

7. Security and Limitations

MailMind AI is an experimental research prototype and is not a production-certified email security service. Users should avoid connecting accounts containing highly sensitive information during early testing.

8. Data Deletion and Contact

Users may request deletion of stored personalization profiles and classification feedback by contacting the developer through the project's GitHub repository.
